# Contributing to Pili Client

Thank you for your interest in improving Pili Client!

While the core engine of Pili Client is distributed as closed-source freeware, this repository (`pili-client-support`) is the open community space where you can actively contribute to:

- 🐛 Reporting bugs and edge cases.
- 💡 Proposing new features and workflow enhancements.
- 🌐 Improving and adding translations (i18n).
- 📚 Refining documentation, usage guides, and examples.

---

## 🐛 Reporting Bugs

Before submitting a bug report:
1. Search the [Issues](https://github.com/Pili-Tools/pili-client-support/issues) tab to see if the problem has already been reported.
2. If not, open a [Bug Report](https://github.com/Pili-Tools/pili-client-support/issues/new?template=bug_report.md) with detailed steps to reproduce, your operating system, and editor version.
3. If relevant, include logs from `Pili Client: Show Logs` in the command palette (make sure to sanitize any confidential tokens or URLs).

---

## 💡 Suggesting Features

We welcome ideas and feature requests!
- Open a [Feature Request](https://github.com/Pili-Tools/pili-client-support/issues/new?template=feature_request.md).
- Clearly explain the problem you are trying to solve and how the proposed feature would work.

---

## 🌐 Translations (i18n)

Pili Client supports multiple languages. If you would like to suggest corrections to existing translations or contribute a new language, feel free to open an issue or pull request in this repository.
