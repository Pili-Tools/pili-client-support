# Security Policy

## Reporting Security Issues

Security and user privacy are core tenets of Pili Client. If you discover a security vulnerability or sensitive data leakage issue, please report it responsibly.

Please **do not** open public GitHub issues for security vulnerabilities.

Instead, please send an email with the subject `[SECURITY VULNERABILITY] Pili Client` to our security contact or use GitHub's private vulnerability reporting feature on this repository.

### What to include in your report:
- Type of vulnerability.
- Full steps to reproduce the issue.
- Proof-of-concept (PoC) or sample request payload if applicable.
- Expected impact.

We will review your submission promptly and coordinate a patch and release before public disclosure.
